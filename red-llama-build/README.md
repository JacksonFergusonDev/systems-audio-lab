# Red Llama Overdrive: Fabrication & Procurement

**Status:** Built and measured | **Role:** Device under test (DUT), and the reason Star Ground exists

This directory contains the build files and parts orders for the **Red Llama Overdrive**, a clone of the Way Huge Electronics pedal. It was the circuit measured with the [RP2040 Oscilloscope](../oscilloscope-rp2040/) and powered by the [Linear Power Regulator](../power-regulator-12v-to-9v/).

Planning this build is also what led to [Star Ground](https://github.com/JacksonFergusonDev/star-ground).

## 1. The "Star Ground" Origin

Partway through planning this pedal, I found that checking the bill of materials (BOM) against my parts drawer by hand kept producing mistakes. Between several suppliers, varying shipping times and checking what I already had, I needed a tool to do it.

I paused the build to write **Star Ground**, a Python app that reads BOMs as structured data and works out what to order.

### The Pipeline

The files in `procurement/` were generated by Star Ground, not written by hand:

1. **Ingestion:** The tool parsed the raw PDF documentation for the Red Llama.
1. **Inventory Subtraction:** It compared the BOM with my `inventory.csv`, a spreadsheet of the parts I already had.
1. **Heuristic Buffering:** It added spares (safety stock) by rule: extra resistors and chips, which are cheap and easy to lose or damage, but no spares for expensive parts such as potentiometers and switches.
1. **Artifact Generation:** It produced the shopping list and assembly guides ordered by component height.

**🚀 [View the Tool / Live App](https://star-ground.streamlit.app/)**

### Generated Artifacts

- **`Shopping List.csv`**: The order list used to buy the parts from Tayda Electronics.
- **`My Inventory Updated.csv`**: The post-build state of the local inventory.
- **`Field Manuals/`**: PDF instructions that list the parts in soldering order, shortest first (resistors, then sockets, then capacitors), so each part stays put while the board is upside down.

## 2. Circuit Topology

Most overdrive pedals use an op-amp and clipping diodes. The Red Llama instead uses a **CD4049 CMOS hex inverter**, a digital logic chip, as an analog amplifier.

- **Gain Stages:** Two inverter stages are cascaded in series.
- **Clipping Mechanism:** Negative feedback holds each inverter in its linear region, where it works as an amplifier. Driven hard, its output transistors run into the supply rails, giving soft, tube-like saturation that squares off into fuzz at high gain.

## 3. Engineering Deviations

The build follows the standard circuit except for one change to the power section, which slightly raises the supply voltage.

### D2 Substitution: Schottky vs. Silicon

The standard schematic uses a **1N4001** silicon diode at position **D2** for reverse-polarity protection. A silicon diode drops about $0.7\text{V}$ (its forward voltage, $V_f$).

In a 9V circuit, that is a noticeable loss:
$$V_{rail} = V_{source} - V_{diode} = 9.0\text{V} - 0.7\text{V} = 8.3\text{V}$$

**The Modification:**
I replaced the 1N4001 with a **1N5817 Schottky diode**. A Schottky diode uses a metal-semiconductor junction rather than a p-n junction, so its $V_f$ is lower: $\approx 0.3\text{V}$ at the few milliamps the pedal draws ($0.45\text{V}$ at the diode's rated $1\text{A}$).

$$V_{rail(mod)} = 9.0\text{V} - 0.3\text{V} = 8.7\text{V}$$

**Result:**
The extra $\approx 0.4\text{V}$ of supply gives the CMOS inverters slightly more room before their output hits the rails. The effect on the sound is small and was not measured.
